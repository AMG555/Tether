01.1

What one character actually costs

A companion is not one generation. It is eight short clips, and every generation can fail or need a second take. Plan for 12 generations per character — that is what buys you retries. Google Flow's free tier gives 50 credits per day, so the arithmetic below decides whether you can afford the model you picked.

01.2

The honest limits of the free tier

Read this before you plan a workflow around it. These are Google's rules, not ours, and they change.

RuleWhat it means for you
50 credits, per dayEnough for 5 Lite or 2 Fast generations. A full 8-clip character is not one day's work.
No rolloverUnused credits are gone tomorrow. Plan in days, not batches.
Clock starts on first generationYour next 50 arrive that many hours later, not at midnight.
Peak-hour pause, ~14:00–17:00 UTCFree accounts may be blocked from video generation in that window. Images and the agent still work.
Cost is per generation, not per clickOne request can return two videos and charge twice.
Clip length 4–8 sOur target is 1–8 s per clip, so a single generation is enough. Do not extend.
Visible watermark in some regionsIndia, South Korea and Vietnam force a visible mark on free output. It will be cropped into your character. Check before you commit.
720p outputYou need roughly 300 px tall. Downscale; never upload footage.

Sources: Google Flow help centre credit table and the current published free-tier rules. Prices move; the planner above is what matters, and you can change the numbers yourself.

01.3

So: yes, you can do it for free — over four or five days

This is the answer to "is 50 credits enough?". For one character, with Veo 3.1 Lite, twelve generations is 120 credits: three days of allowance if you spend nothing else. Assemble the pack whenever you like — the clips keep. If you want a character today, use Omni Flash at 360p (6 credits) and accept softer art, or start from a still image you already have.

02.1

The character image

One still, generated once. This is the frame every animation starts from, so spend your retries here — a bad first frame cannot be animated into a good clip. Paste into Flow's image mode or any image model.

02.3

      

        
Export, then strip the background

        
Flow returns video. You need alpha. The order that works: download the
          clip, keep only the middle frames (the first and last are usually the model settling),
          remove the background, crop tight to the body, then encode.

        

          
SettingValueWhy

          
            
Canvas264 × 280What the built-in companions ship. The player scales to fit, so any size works, but keep every clip identical.

            
Frame rate17 fpsSlower than video, and it is what the art was drawn for. 30 fps doubles the bytes for no visible gain.

            
Duration1–8 sIdle and eyes can be long; walk should be 1–2 s so it loops.

            
Formatanimated WebPRoughly a quarter of APNG at the same quality. APNG and GIF are accepted as fallbacks.

            
LoopforeverA walk cycle that plays once and freezes is a bug the validator refuses.

            
AlphaonWithout it you ship a rectangle.

          
        

        
Background removal: any local tool or keyer. If you generated on a flat green
          screen (the prompt asks for it), a colour key is exact and free.

04.3

      

        
Validate and install

        
Savepoint reads each clip's header before it decodes anything. It will
          refuse a decompression bomb, a path traversal, a still image where an animation is
          needed, and a walk cycle that does not loop — and it names the state that is wrong.
