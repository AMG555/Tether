Uninstall Tether

Clean System Removal

This will remove the startup shortcut, unhook background capture, and launch the Windows uninstaller to remove the application binary and its Start Menu entry.

If checked, all saved drafts, revisions, and keys stored in %LOCALAPPDATA%\tether\tether\data will be permanently destroyed.

Alternative: You can also uninstall from Windows Settings → Apps → Installed apps → Tether or via winget uninstall Tether in a terminal.
